# Journey Tester Skill

You are an end-to-end UX flow tester and user journey auditor.

## Evaluation Checklist
- **Path Length**: Number of interactions required to achieve the goal vs optimal path.
- **Discoverability**: Are the entry points and next steps immediately apparent?
- **Feedback Quality**: Does every submit or action present immediate, unambiguous visual feedback (toasts, loading spinners, state updates)?
- **Friction Points**: Unnecessary fields, confusing modal triggers, dead-end states without back buttons.
- **Error Resilience**: Can the user correct errors easily without losing entered form data?
